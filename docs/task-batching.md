# 同账号多目录合批检查（2026-11-08）

新增随选任务按账号合并临近到期的检查。保持原有配置、文件、保留策略、历史和事务格式；原 bisync 仍独立运行，不迁移或重建历史。

## 运行规则

- 约 2 秒窗口收集到期任务，本地变化、策略修改提前放行等待中的同账号批次。不同账号、后续轮次分开处理。
- 各任务独立完成，不存在“全批完成后才能同步”的等待点。暂停可退出批次等待，慢任务不占住其他任务的元数据或交互传输通道。
- 管理器每轮统一读取配置，工作线程使用该轮内存快照；批次放行后再次读取最新快照，避免等待期间的策略修改被忽略。配置异常仍停止所有工作线程。
- 批次最多共享 5 秒内成功的账号连接及完整目录核验结果；失败结果不缓存。缓存有 128 个条目、4,096 条目录记录的容量限制，超出后逐出，巨大目录不保留已完成缓存副本。
- 目录结果仍包含原始分页、名称、父目录、ID、大小、SHA-1 和传输目录一致性检查。不同目录仍分别列举，不把多个目录假装成一次网盘请求。
- 共享只用于初始只读扫描。恢复、提交、删除、下载、释放前后核验绕过共享缓存；本地删除和仅联机占位更新前增加新鲜身份/版本核验。无变化状态写入优化保持生效。
