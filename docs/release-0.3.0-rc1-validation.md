# 0.3.0-rc1 发布验证

日期：2026-11-08。测试使用当前 Windows x64 / NTFS。正式同步配置及旧历史保存哈希基线；原生试验使用独立生成的目录和 LocalBackend，不改动正式同步目录。

本版通过 216 项 Python 自动测试、41 项 WPF 自检；两项中文菜单已经通过真实资源管理器的显示、图标及点击链路验收。原六任务配置保持不变。

## 稳定性范围

- 删除含仅联机、完整缓存、空文件、只读文件及普通本机修改的任务，检查正文、文件身份、只读属性、云端替身内容和历史保留。
- 删除后分别按仅联机、始终保留重新添加同目录，确认相同正文不重复上传/下载，缺少的离线正文按策略下载；旧历史字节不变，新任务不冒充旧任务。
- 原生双任务同步、只读文件接管及更新、过期批次删除/覆盖防护。
- 11 个持久化关键点终止进程并重新启动；JSON 原子替换前后分别终止进程，核验完整旧值/新值。
- 双任务合批、空闲状态文件不写入、本地通知唤醒、策略变更、监听故障降级与单任务暂停隔离。
- 4,294,967,419 字节文件三轮完整 SHA-1；其中一轮三个并发读者；重复释放再下载，断开提供程序后离线校验。三轮约 10.2 / 13.1 / 11.9 秒，提供程序峰值工作集 29,515,776 字节（约 28.1 MiB）。这些是本机样本值。
- 中文菜单的文件、文件夹、同步根策略，立即释放缓存、脏文件先上传再释放和暂停时保存策略。

## 发布检查

公开源码通过显式清单导出，不包含账户配置、凭据、用户目录、运行数据库或未脱敏日志。安装器、便携包和源码包需通过 SHA-256、ZIP CRC、逐文件比较、冻结模块与源码比对、运行诊断及递归隐私检查。GitHub 对发布提交执行 Windows CI，上传后重新下载附件核对校验值。

本机原始报告保留于 `runtime/release-0.3.0-rc1-20261108` 以及生成的 `tests/runs` 中，不随源码发布。失败记录保留，不由后续成功覆盖。

本次不证明整机物理断电、硬件缓存掉电、所有客户端竞争时序或长期全文件库安全。真实 115 云端专项证据与其边界见 [文件随选专项验收](files-on-demand-acceptance.md)。
