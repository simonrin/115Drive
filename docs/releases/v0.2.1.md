# 115Drive v0.2.1

Windows 上的 115 网盘双向同步工具。通过原生托盘查看同步状态，在设置窗口中选择本地文件夹、扫码连接账户和管理自启动。

这是面向 Windows 10/11 x64 的公开测试版本，非 115 官方产品。

## 下载

| 附件 | 用途 |
| --- | --- |
| `115Drive-Setup-0.2.1-x64.exe` | 全新安装，默认目录为 `%LOCALAPPDATA%\115Drive` |
| `115Drive-0.2.1-windows-x64.zip` | 便携包，解压到独立目录后运行 `115Drive.exe` |
| `115Drive-0.2.1-source.zip` | 本版本源码、构建脚本及修改版 OpenList 对应源码 |
| `SHA256SUMS.txt` | 上述文件的 SHA-256 校验值 |

安装包和便携包均自带 Python 运行时、rclone 及修改版 OpenList，无需另外安装 Python。EXE 尚未做数字签名。

## 本版功能

- Windows 递归文件事件触发本地核对，60 秒定期完整扫描兜底；监听异常时退回 2 秒轮询并自动重建。
- 云端索引与本地快照仅在内容变化时写入，核验记录单独保存并验证正文摘要。
- 临时网络故障自动重试；授权、磁盘空间、健康标记等问题等待处理，避免反复无效重试。
- 分别显示最近检查、最近同步成功及最近文件传输时间，托盘显示重试倒计时。
- 本地文件夹与网盘根目录下的 `/115Drive` 双向同步，支持新增、修改、删除和空目录。
- 固定高度的单行状态，区分扫描、校验、上传、下载、续传和暂停。
- 暂停时中断当前文件传输，保留已确认分片；恢复时先校验，再传输剩余部分。
- 大文件上传保留 OSS 分片会话，下载保留经过校验的数据块；程序重启后继续恢复。
- 最近活动显示目标文件夹和时间，单击打开文件、右键打开所在目录；原路径不存在时标记“已移动或删除”。
- 原生设置窗口、Windows 登录自启动、同步目录复制校验后切换。
- 目录索引缓存、增量检查和属于本工具的临时文件清理。

## 开始使用

1. 安装，或解压便携包后运行 `115Drive.exe`。
2. 在设置中选择一个空的本地文件夹。
3. 用手机 115 生活 App 扫码并确认，等待连接测试通过。
4. 点击托盘查看状态。115 官方桌面客户端无需保持后台运行。

## 同步行为

- 删除会双向传播；恢复副本默认关闭，本工具不是历史版本备份。
- 首次合并时同名文件采用云端版本；后续两端冲突保留带标记的另一版本。
- 续传复用已确认的分片；中断时未完成的分片可能重传。小文件按整文件重试。
- 上传恢复仍需从本地读取并校验文件，但已确认的云端分片不会重复上传。
- 云端采用轮询，延迟受目录规模、网络和服务限制影响；没有按需下载占位符或资源管理器状态图标。
- 普通网盘会话可能失效并需要重新扫码，也可能替换已有的同类小程序登录。
- 安装器只向空目录安装，暂无自动升级。已有使用者更新前应保留配置和同步历史，避免重新初始化。

## 已有验证

两批同步优化在 Windows 本机通过 125 项 Python 测试、32 项托盘自检和 4 个 Go 包检查。已验证真实双向新增、同大小修改、删除，以及漏通知补扫、监听读取异常恢复和同步连接中断后的自动重试；上传内容经云端 SHA1 和下载回读核对。详细结果和边界见 [同步优化验证记录](../sync-optimization-verification.md)。

本版发布检查还包括安装器与便携包逐文件一致性、ZIP 完整性、源码摘要、12 个打包后 Python 模块与源码一致性，以及后台诊断。程序保留原有同步历史与续传保护，不自动执行重新初始化。

首次完整比对仍可能较慢；此前测试首个上传等待约 316 秒，后续变化约 20–36 秒。定期扫描与监听恢复在当前同步操作结束后执行，网络中断试验只影响临时同步进程，没有断开整机网络。

这些结果说明本次测试条件下的行为，不代表所有网络、账号、文件大小或 Windows 版本均已验证。详细限制、隐私说明和构建方式见仓库 README。
