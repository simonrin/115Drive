# 115Drive v1.0.2 — 托盘状态与资源管理器布局

适用于 Windows 10/11 x64。已有 1.0.1 的用户可运行 `115Drive-Setup-1.0.2-x64.exe`，选择原安装目录覆盖升级。

- 托盘、设置和文件夹徽标统一使用红蓝云朵。托盘面板和设置页共用字体及主题色。
- “立即同步”上方以镂空图标显示同步中、完成、异常和暂停。悬停查看详情，点击感叹号可查看出错任务。
- 在已配置任务的程序目录中运行 `.\sync-navigation-layout.ps1`，可逐个复制本地文件夹的视图模式、图标大小、排序和分组。以后更改了本地布局，可再次运行。

安装包、便携包和对应源码包的 SHA-256 均列在 `SHA256SUMS.txt` 中。
