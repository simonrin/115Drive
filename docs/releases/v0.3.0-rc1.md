# 115Drive v0.3.0-rc1

同一 115 账号的多个目录可以分别同步，并选择“始终保留”或“仅联机”。本版统一同步设置页面，加入安全解除任务、中文文件右键菜单和多任务调度优化。

这是 Windows 10/11 x64 的公开候选测试版，非 115 官方客户端。

## 下载

| 附件 | 用途 |
| --- | --- |
| `115Drive-Setup-0.3.0-rc1-x64.exe` | 向空目录安装，内置运行依赖 |
| `115Drive-0.3.0-rc1-windows-x64.zip` | 便携程序及依赖 |
| `115Drive-0.3.0-rc1-source.zip` | 对应源码、测试、构建入口及第三方源码 |
| `SHA256SUMS.txt` | 文件 SHA-256 校验清单 |

EXE 尚未进行代码签名。安装器仍只接受空目录，不会覆盖已有配置或自动升级旧安装。已有用户更新前应退出应用并备份配置和同步历史；不要重新初始化同步目录。源码运行目录不可用便携包整体替换。

## 本版变化

- Windows 原生 CfAPI 占位、打开时下载、离线保留和释放空间；文件及子目录可设置例外策略。
- “同步与备份”集中管理所有任务。运行中的删除按钮灰色禁用，暂停完成后变红可用。
- 删除任务只解除同步：完整本机文件及历史保留，仅联机占位直接移除，不要求下载，也不调用网盘删除接口。未完成事务或未同步的部分内容仍受保护。
- 右键“始终保留在此设备上”配绿色勾选图标，“释放空间”配蓝色云朵图标；菜单只针对 115Drive，Windows 11 可从“显示更多选项”进入。
- 多目录合批检查，空闲退避，无变化时不重写同步状态；独立任务检查可在另一任务传输时继续。上传通道仍有并发上限，不承诺所有传输同时执行。
- 加强云端分页完整性、文件 ID 提交、冲突保留、持久事务、进程中断恢复及大文件内存控制。

## 验证与限制

本次通过 216 项自动测试、41 项原生界面自检、真实资源管理器中文菜单点击、隔离目录的删除/重加、双任务调度、只读文件、脏数据保护、11 个关键点进程强杀恢复，以及 4 GiB 文件三轮完整哈希校验。安装包还需通过安装器解包、便携包逐文件比对、冻结模块与源码一致性、隐私检查及下载校验；详细发布证据见 [验证说明](../release-0.3.0-rc1-validation.md)。

- 删除后重加同目录会建立新任务并重新扫描，内容相同的文件跳过传输；旧历史尚不能自动接续。临时停用建议使用暂停/启动。
- 本轮原生稳定性回归使用隔离本地云端替身；此前真实 115 大文件与并发验证范围见 [专项验收](../files-on-demand-acceptance.md)。不将替身测试等同于全部真实云端场景。
- 中断测试是进程强杀，不是整机物理断电；未覆盖所有 Windows 版本和长期全库运行。
- 新任务的云端替换/删除历史会占用空间，暂不自动清理。旧同步任务的恢复副本设置保持原样。
