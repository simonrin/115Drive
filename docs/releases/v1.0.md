# 115Drive 1.0

版本号统一为 1.0，关于页面、EXE 安装包、便携包、源码包和安装清单保持一致。

包含同账号多目录同步、文件随选、逐目录保留策略、合批检查、路径增量核验、SQLite 状态及独立云端同步历史区。沿用 0.3.0-rc4 的同步引擎，本次没有更改同步判断或迁移用户数据。

安装包可在原安装目录覆盖升级，保留账号配置、同步任务、文件和历史。源码运行目录继续使用源码更新方式。

此前 397 项回归和真实云端删除/恢复验收仍是同步引擎的证据；本次仅重新验证版本显示、发行内容一致性和覆盖升级。详见 [删除可见性修复](../local-delete-visibility-fix.md) 和 [同步效率验收](../sync-efficiency-validation.md)。版本号调整不扩大已有验收范围，物理断电、长期运行和服务端原子条件修改仍不能由此前测试推导。
