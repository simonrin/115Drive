# 115Drive v0.3.0-rc2

安装包现在支持在原安装版或便携版程序目录直接升级，无需重新扫码或重新创建同步任务。

## 使用方法

运行 `115Drive-Setup-0.3.0-rc2-x64.exe`，确认选中原来的**程序目录**，点击“升级并打开”。正在运行的安装版会自动识别；便携版也可通过“浏览…”选择原程序目录。不要选择存放电子书、图片等内容的同步文件夹。

升级器会等待同步停止，然后备份并替换程序文件。完成后恢复原有任务的运行/暂停状态；升级前已暂停的任务仍保持暂停。账号配置、任务 ID、路径、保留策略、云端文件、本机完整文件、仅联机占位和同步历史均不重置。

`config.json`、`runtime` 中的账户与历史数据、日志、恢复副本、`tray/settings.json`、自定义 `filters.txt` 及其他不在安装清单中的文件均保留。旧程序备份与升级记录存放在原目录的 `runtime/private/install-upgrades`，不上传到 GitHub。

若文件被占用或升级中断，安装器会尝试恢复旧程序；仍被占用或文件已被用户另行修改时会停止并保留备份。解除占用后，重新运行同一安装包恢复并继续。不要手工删除 `installer-active.json` 来强行启动不完整的程序。

## 下载

| 附件 | 用途 |
| --- | --- |
| `115Drive-Setup-0.3.0-rc2-x64.exe` | 首次安装或原目录覆盖升级 |
| `115Drive-0.3.0-rc2-windows-x64.zip` | 便携程序及运行依赖；已有便携目录建议使用 EXE 升级 |
| `115Drive-0.3.0-rc2-source.zip` | 对应源码、测试和第三方源码 |
| `SHA256SUMS.txt` | SHA-256 校验清单 |

本版保留 rc1 的多目录文件随选、中文右键菜单和调度优化。仍为 Windows 10/11 x64 候选测试版，安装包未签名。升级器支持安装版与便携版，不把源码工作目录自动转换为安装版，也不迁移程序目录。

230 项自动测试和 41 项原生界面自检通过。最终 EXE 已完成旧版原目录升级、重复安装和全新安装验收；24 个受保护文件保持原样，仅联机占位没有触发下载。另验证了混合暂停状态恢复、损坏安装包拒绝、替换失败回滚、进程中断后重试，以及其他安装实例保护。详见 [升级验证](../installer-upgrade-validation.md)。进程终止测试不等同于整机物理断电。
