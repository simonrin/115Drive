# 115Drive

Windows 上的 115 网盘双向同步工具，提供原生托盘、同步进度和设置窗口。

> 社区项目，非 115 官方客户端。使用普通网盘会话连接；接口可能变化，失效时需重新扫码。

**当前版本：0.2.0 · Windows 10/11 x64**

## 功能特点

- **双向同步**：自动同步本地目录与 115 网盘，删除操作也会双向传播。
- **原生界面**：提供 Windows 托盘、同步进度和设置窗口。
- **扫码连接**：使用手机 115 生活 App 扫码，连接验证通过后自动同步。
- **开箱即用**：提供安装包和便携包，内置运行依赖，无需另装 Python。

## 安装条件

安装包自带 Python 运行时、rclone 和本项目修改版 OpenList，**无需另外安装 Python、Go 或 OpenList，也不需要安装或保持 115 官方电脑客户端运行**。下方“源码与构建”中的开发依赖仅供自行编译使用。

| 项目 | 安装前要求 |
| --- | --- |
| 操作系统 | Windows 10/11 x64，适用于 Intel/AMD 64 位电脑。 |
| 系统组件 | .NET Framework 4.8 或 4.8.1；精简系统需确认相关组件齐全。 |
| 同步位置 | 首次配置选择有写入权限的本地空文件夹或尚未创建的文件夹；可放在其他盘。不能选择磁盘根目录、网络共享路径、目录联接或符号链接，也不能与程序目录重叠。 |
| 网络与账户 | 电脑能访问 115 的登录、文件和传输服务；有可用的 115 账号、足够的网盘空间，以及已登录的手机 115 生活 App。 |
| 本机端口 | `127.0.0.1:5244`、`127.0.0.1:5245` 未被其他程序占用，且本机回环访问未被拦截。同一台电脑只运行一份 115Drive，无需开放路由器端口。 |

## 首次配置与扫码连接

整个过程在原生设置窗口中完成，无需打开网页或手动复制访问令牌、刷新令牌。

### 1. 先确认本地同步位置

1. 在 **“同步与备份” → “同步文件夹”** 查看当前路径。默认是当前用户主目录下的 `115Drive`，通常为 `%USERPROFILE%\115Drive`。
2. 点击 **“更改位置”**，通过 **“浏览…”** 选择空文件夹，或填写完整路径，例如 `D:\115Drive`。
3. 点击 **“检查并保存位置”**；出现“位置已保存。请到‘账户’扫码连接。”后，再继续扫码。即使使用默认位置，也可将该路径填入并检查，以确认目录符合首次配置要求。
4. 按需保留或取消 **“登录 Windows 时自动启动 115Drive”**。设置自动保存，首次验证和初始化成功后才注册同步任务。

**程序目录与同步目录是两个不同的位置。** `%LOCALAPPDATA%\115Drive` 存放程序、配置和缓存；上面选择的本地文件夹存放实际同步文件，不要将二者设为同一目录。

本地目录对应网盘根目录下的 **`/115Drive`**。连接时会检查此目录，不存在则创建；已有内容会参与首次同步，不会同步整个网盘。

### 2. 用手机扫码授权

1. 切换到左侧 **“账户”**，点击 **“扫码连接”**，等待二维码显示。
2. 打开手机 **115 生活 App** 的扫一扫功能，扫描电脑上的二维码，并在手机端确认登录。
3. 电脑显示“扫码已确认，正在连接并测试同步…”后，保持电脑联网，等待自动验证完成，无需再复制 Cookie 或令牌。
4. 程序会在独立测试目录检查上传、下载、修改、删除及冲突处理；测试通过后进行首次目录同步，再启动后台任务。若云端已有较多文件，首次下载可能需要较长时间。

当前扫码方式使用普通网盘会话，可能替换已有的微信小程序登录。扫码成功仅代表授权完成；应继续等待连接测试和首次同步结果。

### 3. 确认同步已启用

- 点击 Windows 通知区域中的 115Drive 图标；找不到时检查隐藏图标区域。
- 托盘会依次显示目录检查、传输或校验状态，结束后显示 **“所有文件已同步”**。设置中的账户状态会显示 **“已连接 · 双向同步 /115Drive”**。
- 可在本地同步目录放入一个无关紧要的小文件，等待其出现在网盘 `/115Drive`；再从手机向该云端目录上传另一个测试文件，确认本地收到。
- 托盘可 **“立即同步”**、**“暂停同步”**、**“恢复同步”**；点击齿轮或右键托盘选择 **“设置”**，可再次打开设置窗口。

**删除会双向传播，恢复副本默认关闭。** 清理测试文件时，另一端也会删除对应文件；重要资料应另留独立备份。
首次连接请选择空的本地目录；若首次合并遇到同名文件，会使用云端版本。
这不是按需下载：云端 `/115Drive` 内的文件会保存完整本地副本。

自动同步在**登录 Windows 后**启动；关机、睡眠或断网期间不能传输。
无需保持设置窗口或 115 官方客户端打开；[隐私说明](PRIVACY.md)介绍凭据与缓存的本机保存位置。

### 首次连接常见情况

| 情况 | 处理方法 |
| --- | --- |
| 二维码过期，或在手机上取消了登录 | 回到“账户”重新点击“扫码连接”，扫描新二维码并确认。 |
| 提示本机后台正在启动或暂时不可用 | 稍候重试；若持续出现，检查是否已有另一份 115Drive、OpenList 或其他程序占用 5244/5245 端口。 |
| 手机已确认，但电脑显示连接或同步测试失败 | 以电脑显示的错误为准，先检查网络、磁盘空间与目录写入权限；处理后重新扫码。未通过验证时，不要当作已启用同步。 |
| 提示文件夹不为空或路径不符合要求 | 选择另一个普通本地空目录并“检查并保存位置”，不要清空已有资料来绕过检查。 |
| 首次同步完成后提示计划任务创建失败 | 检查 Windows 任务计划程序及当前用户权限；受管理的电脑需由管理员处理策略限制。 |
| 日后登录会话失效 | 在“账户”点击“暂停以重新连接”（或先暂停同步），等待已暂停，再点击“重新扫码连接”。验证通过后沿用已有同步历史。 |

## 源码与构建

```text
tray/                  WPF 托盘和原生设置窗口
twodrive.py            同步后台
desktop_service.py     独立后台 EXE 入口
desktop_settings.py    原生设置接口
folder_change.py        目录复制、校验和事务恢复
cloud_scan.py           云端变化检查与缓存
tests/                 单元测试、隔离 rclone 验证
packaging/             Windows 编译和安装包脚本
third_party/           修改版 OpenList 对应源码、前端源码和构建入口
licenses/              第三方许可证
```

构建环境：Windows x64、Python 3.11、Go 1.27.2、系统 .NET Framework 编译器。

```powershell
python -m pip install -r requirements-build.txt
python packaging/fetch-rclone.py
powershell -ExecutionPolicy Bypass -File third_party/build-openlist.ps1
powershell -ExecutionPolicy Bypass -File packaging/build-release.ps1
```

输出在 `dist/`：便携 ZIP、安装 EXE 和 SHA256SUMS。构建使用空的 `build/release`，重复构建请使用新的干净工作目录。

## 发布与隐私

只提交本源码目录。不要提交运行中的程序目录：`config.json`、`runtime/`、`logs/`、`recovery/`、`tray/settings.json` 和凭据均已加入忽略规则。

公开发布时同时提供源码及对应的第三方源码。发布包内包含修改版 OpenList 对应源码和前端源码。源码提交与创建 GitHub Release 可分别进行，`dist/` 中大体积二进制应作为 Release 附件上传。

安装包未进行代码签名；发布前可使用自己的代码签名证书签名。当前机器验证不等于已在所有 Windows 版本上验证。

下载后可运行 `Get-FileHash .\115Drive-Setup-0.2.0-x64.exe -Algorithm SHA256`，
与同一 Release 的校验清单对比。安装器只支持空目录，暂不提供自动升级。

发布者可直接使用 [GitHub 发布步骤](docs/PUBLISHING.md) 和 [v0.2.0 发布说明](docs/releases/v0.2.0.md)。
源码贡献见 [CONTRIBUTING.md](CONTRIBUTING.md)。
